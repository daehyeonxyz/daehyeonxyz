## About

An industrial engineering background, now spent on two questions: how to give a language model durable context about one person, and whether the result actually holds up when a person uses it. The first is engineering, the second is research, and I would rather not do either one alone.

Currently at **UXC Lab, Kyung Hee University**, working on LLM-based HCI.
